# Security policy

Report suspected vulnerabilities through this repository's private
[GitHub vulnerability reporting form](https://github.com/1funnel/1funnel-api-samples/security/advisories/new).
Do not include credentials, signing secrets, OTP codes, personal data or exploit
details in a public issue. If private reporting is unavailable, contact
[1Funnel Support](https://developers.1-funnel.org/resources/support) and request a
private security reporting channel before sharing sensitive material.

These are teaching samples, not production deployment blueprints. Follow each
sample's operational boundaries. Use current runtime security updates and never
disable TLS verification. Repository tests use synthetic loopback fixtures;
passing them does not establish live platform behavior or production security.
